# Quick Launch: Duck.ai

A simple Firefox toolbar button that opens [Duck.ai](https://duck.ai/) in a new tab.

I just wanted a one-click shortcut to Duck.ai that lived on my toolbar, separate from my bookmarks — so I vibe-coded this extension :)

**This is an unofficial personal project. It is not affiliated with, endorsed by, or associated with DuckDuckGo.**

## What it does

Click the toolbar button → Duck.ai opens in a new tab. That's it.

## Install

**From Firefox Add-ons (recommended):** *[link to be added once published]*

**Manually (temporary, for development):**
1. Open `about:debugging` in Firefox
2. Click **This Firefox** → **Load Temporary Add-on**
3. Select `manifest.json` from this folder
4. Note: temporary add-ons are removed when Firefox restarts

## Files

| File | Purpose |
|------|---------|
| `manifest.json` | Extension configuration |
